# ✨ Aurelia Jewels

Aurelia Jewels is a jewellery website project designed to showcase elegant
jewellery collections through a clean and attractive user interface.

## 📌 About the Project

The Aurelia Jewels project aims to provide an appealing online jewellery
browsing experience. It focuses on website design, product presentation,
and creating a user-friendly interface.

## 🚀 Features

- Elegant and modern website design
- Jewellery product showcase
- User-friendly navigation
- Responsive layout for different screen sizes
- Attractive styling and visual presentation

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
